## 🎯 What is KeyDash?

KeyDash is a competitive typing race application inspired by platforms like Keymash.io. Players race to type a passage of text as fast and accurately as possible, either against AI-powered bots in solo mode or against real players in multiplayer rooms.

The app tracks every keystroke, records per-word performance metrics, and provides a full post-race analytics suite including a performance chart (WPM over time), detailed statistics, and a complete replay system that lets you watch your race back at variable speed.

Two modes of play:

- **⚡ Quick Play** — Instant solo race against AI bots. No account needed. Bots have realistic typing patterns with Gaussian variance, burst/pause cycles, and difficulty-scaled WPM ranges so there's always a competitive match.
- **🌐 Multiplayer** — Create a room, get a 6-character code, share it with friends. Everyone gets the same text and races in real-time. The host controls when the race starts, and all players see each other's live progress, WPM, and current word.

## ✨ Features

### Core Gameplay
- **Ultra-smooth typing engine** — No visible input element. Keystrokes are captured at the window level with individual character spans updating in ~30ms. The cursor uses a glowing 2.5px bar with smooth auto-scroll. Zero layout shift. The result is a typing experience that feels like sliding on water.
- **Real-time race tracks** — Every player (human or bot) has a live progress bar with gradient fills, glow tips, and placement tags updating at 60fps.
- **4 difficulty levels** — Casual (15–35 WPM bots), Competitive (25–55), Expert (40–85), and Insane (70–140). Each level has bots spread across the range so you always beat some and get pushed by others.
- **Word bank system** — 300+ common words for Easy, 70+ medium-complexity words, and 50+ advanced words. Text is generated dynamically per race with difficulty-appropriate vocabulary.

### Post-Race Analytics
- **Statistics tab** — WPM (to 2 decimal places), accuracy percentage, elapsed time, mistake count, character count, and the full race text with errors highlighted in accent color.
- **Performance tab** — Dual-axis Chart.js graph showing per-word WPM (orange line, left axis) and seconds-per-word (blue dots, right axis) with a running average overlay. Hover any point to see exact metrics.
- **Replay tab** — Watch your entire race played back with a cursor moving through the text showing correct/incorrect characters in real-time. Play/pause, seekbar, and variable speed (0.5x / 1x / 2x / 4x).

### Multiplayer
- **Room code system** — 6-character alphanumeric codes auto-generated by a Postgres trigger. Excludes ambiguous characters (I, O, 0, 1) to prevent misreads.
- **Waiting room** — Host sees a shareable code with copy button. Participants see "Waiting for host to start..." with no Start button (host-only control). Player list updates live as people join.
- **Synchronized countdown** — Host's 3-2-1-GO countdown broadcasts to all participants so everyone starts at the same moment.
- **Live progress sync** — Player progress, WPM, and finish state broadcast via Supabase Realtime at 20 updates/second using Broadcast (no database writes during race = low latency).
- **Consistent results** — Placements derived from finish time across all browsers, so the winner is the same on every screen.

### AI Bot Engine
- **Gaussian noise** on keystroke intervals (not uniform random) for natural variation
- **Burst typing** — 30% chance of entering a fast burst (1.2x speed) for 0.5–1.5 seconds
- **Random pauses** — 8% chance per tick of a 200–500ms pause simulating thinking
- **Fatigue simulation** — 0.04% slowdown per second (max 5% over a full race)
- **Difficulty spread** — Each level has bots at different points in the WPM range, so there's always one slower and one faster than you

### UX Details
- **Name validation** — Can't start without a name. 5 suggested gamer names (ShadowTyper, NeonFingers, KeyPhantom, VoltStrike, CyberPulse) appear as clickable chips when the input is empty.
- **Procedural avatars** — Every player gets a unique SVG avatar generated from a seed number with 5 pattern variations and 10 color pairs.
- **Animated countdown** — Full-screen overlay with 130px numbers, scale-in animations, expanding pulse rings, and a color shift from orange to green on "GO".
- **Dark theme** — Deep charcoal background with noise texture, subtle grid overlay, and ambient gradient orbs for atmosphere.

## ⚙️ How It Works

### Typing Engine

The typing engine is the heart of KeyDash. Here's what makes it feel smooth:

1. A `keydown` listener on `window` captures every keystroke — no `<input>` element involved. This eliminates autocorrect, autocomplete, and browser-level input latency.

2. Each character in the race text is an individual `<span>`. When you type a correct character, we flip that span's CSS class from `text-txt-g` (ghost gray) to `text-txt-1` (white). Wrong characters get `text-neon-red` with a red background tint. The transition duration is 30ms — fast enough to feel instant, smooth enough to not flicker.

3. The cursor is a `::before` pseudo-element on the active character span — a 2.5px accent-colored bar with a glow shadow and a blink animation. It moves to the next span on each keystroke with zero layout shift.

4. WPM is calculated as `(correctChars / 5) / elapsedMinutes` — the standard "words per minute" formula where 1 word = 5 characters.

5. Per-word timing is recorded: when you press space to complete a word, we log `{ word, startTime, endTime, wpm, secondsPerWord }`. This powers the Performance chart.

6. Every 80ms during the race, we snapshot `{ time, charIndex, charStates[] }` into a replay buffer. After the race, the Replay tab plays these frames back at variable speed.

### Multiplayer Sync

Real-time multiplayer uses Supabase Realtime's **Broadcast** feature — messages go directly between connected clients via WebSocket without touching the database:

```
Player A types → broadcastProgress() → Supabase WebSocket → Player B sees progress
                 (throttled to ~20/sec)      (~50-150ms)
```

The race text is stored in the database when the room is created. When the host starts the countdown, a `countdown_start` event broadcasts the text to all participants so everyone races on the same words. During the race, only progress/WPM/finish state are broadcast — no database writes until the race ends.

### State Management

All game state lives in a single Zustand store (`src/lib/store.ts`). The store handles:

- Race initialization (text generation, player/bot setup)
- Keystroke processing (character matching, WPM calculation, word timing)
- Bot simulation (Gaussian noise, burst/pause, fatigue)
- Countdown synchronization
- Multiplayer broadcasting and receiving
- Replay recording

React components subscribe to specific slices of the store, so only the affected parts of the UI re-render on each keystroke.

## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/YOUR_USERNAME/keydash.git
cd keydash

# Install
npm install

# Run (works immediately — Quick Play with bots, no backend needed)
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Enter a name, pick difficulty, hit Quick Play.

For multiplayer, see the [Setup Guide](#-setup-guide) below.

## 🛠️ Setup Guide

### Multiplayer Setup (Supabase)

<details>
<summary><strong>Step 1: Create Supabase Project</strong></summary>

1. Go to [supabase.com](https://supabase.com) → New Project
2. Name it, set a database password, choose the region closest to your players
3. Wait ~2 minutes for provisioning
</details>

<details>
<summary><strong>Step 2: Run Database Migration</strong></summary>

1. Supabase Dashboard → **SQL Editor** → New Query
2. Paste the entire contents of `supabase/migrations/001_schema.sql`
3. Click **Run**

This creates all tables, indexes, triggers (auto room code generation, stats update), RLS policies, and enables Realtime.
</details>

<details>
<summary><strong>Step 3: Verify Realtime</strong></summary>

Go to **Database → Publications** → click `supabase_realtime` → confirm `race_rooms` and `race_participants` are listed.

Or verify in SQL Editor:
```sql
SELECT * FROM pg_publication_tables WHERE pubname = 'supabase_realtime';
```
</details>

<details>
<summary><strong>Step 4: Get API Keys</strong></summary>

Dashboard → **Settings → API** → copy:
- **Project URL** → `NEXT_PUBLIC_SUPABASE_URL`
- **anon public key** → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
</details>

<details>
<summary><strong>Step 5: Configure Environment</strong></summary>

```bash
cp .env.example .env.local
```

Edit `.env.local`:
```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci...
```
</details>

<details>
<summary><strong>Step 6: Enable Anonymous Auth</strong></summary>

Dashboard → **Auth → Sign In / Providers** → toggle **Allow anonymous sign-ins** ON → **Save changes**

This lets players race without creating an account.
</details>

<details>
<summary><strong>Step 7: Restart Dev Server</strong></summary>

```bash
# Stop server (Ctrl+C), then:
npm run dev
```

Create Room should now work. You'll see a 6-character room code to share.
</details>

### Deploy to Vercel

```bash
git add . && git commit -m "KeyDash v1"
git push origin main
```

1. [vercel.com](https://vercel.com) → Import from GitHub
2. Add the same environment variables from Step 4
3. Deploy

## 🗺️ Roadmap

### Coming Soon

- **Global Leaderboard** — Persistent rankings by best WPM, win rate, and total races. Profile pages with race history graphs.
- **Ranked Matchmaking** — ELO-based rating system that matches players of similar skill. Seasonal rankings with tier badges (Bronze → Diamond).
- **Custom Text Packs** — Upload your own text passages or choose from curated categories: code snippets, famous quotes, song lyrics, programming documentation.
- **Practice Mode** — No bots, no timer. Just type and track your improvement over time with historical WPM/accuracy trends.
- **Spectator Mode** — Watch live races without participating. See all players' keystrokes in real-time.
- **Mobile Support** — Touch-optimized typing interface with on-screen keyboard integration.
- **Room Chat** — In-lobby text chat and post-race reactions.

### Advanced Features

- **Tournament System** — Bracket-style elimination tournaments with automated matchmaking, round timers, and spectator view. Support for 8/16/32/64 player brackets.
- **Team Races** — 2v2 or 3v3 relay-style races where team members type sequential sections of the text. Combined WPM scoring.
- **Anti-Cheat v2** — Server-side keystroke validation with Supabase Edge Functions. Pattern analysis for macro/bot detection: keystroke interval variance, impossible WPM bursts, copy-paste detection, and trust scoring.
- **Achievement System** — Unlockable badges for milestones: first 100 WPM race, 10-race win streak, 99%+ accuracy, midnight racer, and more.
- **Custom Themes** — Player-selectable color schemes, font choices, and cursor styles. Unlockable themes through achievements.
- **API & Webhooks** — Public API for race results and player stats. Webhook notifications for race completions, new records, and tournament events.
- **OAuth Integration** — Sign in with Google, GitHub, Discord. Link accounts for persistent profiles and cross-device progress.
- **Analytics Dashboard** — Detailed typing analytics: heatmaps of problem keys, speed-by-word-length graphs, accuracy trends over weeks/months, comparison with global percentiles.
- **Multiplayer Scaling** — Dedicated Supabase Realtime instances for high-traffic events, regional server routing for lowest latency, and room sharding for 50+ concurrent rooms.
